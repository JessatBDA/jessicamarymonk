Checks covered authenticated uploads, anonymous/normal-user denial, cross-origin denial, forged image bytes, the 3 MB size limit, persistent metadata, ordered multiple images and WebP serving. Draft images were inaccessible through both `/media` and direct private Storage URLs. Publishing allowed the referenced images; unpublishing revoked anonymous access through both paths. Test image files contained synthetic flat colours and were removed.

Vercel’s protected-preview HTTP checks passed for the homepage, biography and login (200); `/admin` redirected to login (307). No localhost references were present in those responses.
