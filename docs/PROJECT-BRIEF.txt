# PROJECT: Jessica Mary Monk — Artist Website, Public Art, Shop & Engagement Platform

## 1. Project overview

Build a complete, professional, responsive website for **Jessica Mary Monk**, a British public artist, painter and illustrator.

This is a brand-new application built from scratch.

I have attached three screenshots of a website concept created in Figma. These screenshots are the primary visual references. There is no existing source code to transfer.

The website must serve four purposes:

1. Present my professional artistic practice, with public art and community installations as the primary focus.
2. Showcase my paintings, illustrations, commissions and other creative work.
3. Support an online shop selling original artwork, prints and other physical or digital products.
4. Collect and analyse public engagement feedback for individual art projects.

I also require a secure private admin dashboard where I can manage all these functions without editing code.

**Build this as one integrated application, sharing a single database and authentication system.**

## 2. Technology and architecture

Use:

- Next.js with App Router.
- TypeScript.
- Tailwind CSS.
- Supabase PostgreSQL for structured data.
- Supabase Auth for administrator authentication.
- Supabase Storage for artwork and product photographs.
- Vercel-compatible deployment.
- Stripe integration when ecommerce payments are enabled.

Requirements:

- Clean, modular, maintainable architecture.
- Reusable components.
- Proper separation of frontend, server-side logic and database access.
- Secure authentication and authorisation.
- Appropriate database migrations.
- Environment variables for credentials.
- No hardcoded secrets.
- No dependencies on any of my other websites or applications.
- No production deployment without my approval.

Use a new, dedicated Supabase project.

Implement the foundation for all three admin sections now, even where certain commercial features will be activated later.

## 3. Visual identity and design

**This is extremely important.**

The attached screenshots represent the visual style I want to retain.

The design should be artistic, contemporary, understated and professional.

### Preserve these design elements

- White and light grey backgrounds.
- Black and charcoal typography.
- Expressive black brushstroke lines dividing sections.
- Spacious layouts with generous whitespace.
- Large artwork images.
- Clean, minimal navigation.
- An editorial portfolio aesthetic.
- A mixture of elegant typography and hand-drawn artistic elements.

Recreate the black brushstroke dividers as reusable SVG components inspired by the screenshots.

Do not introduce generic corporate dashboard styling into the public website.

Avoid unnecessary gradients, excessive rounded cards, bright accent colours and distracting animations.

The website should resemble a contemporary artist's exhibition catalogue.

### Responsive behaviour

- Fully responsive on mobile, tablet and desktop.
- Mobile-first design.
- Clear and accessible navigation.
- No horizontal scrolling.
- Artwork must retain appropriate aspect ratios.
- Images should be optimised without compromising presentation quality.
- All forms must work comfortably on mobile devices.

## 5. Private admin dashboard

Create a protected administration area at `/admin`.

The admin dashboard should use the same underlying application but have its own practical interface.

The dashboard must have three main sections:

**1. Website & Profile**

**2. Shop & Orders**

**3. Project Engagement**

Include a dashboard homepage summarising recent activity and providing navigation to each section.

Use Supabase Auth for administrator login.

Do not allow public registration for administrator accounts.

Administrator access must be controlled through secure server-side authorisation, not editable user metadata.

### ADMIN SECTION 1 — Website & Profile

This section should operate as a simple content management system.

I must be able to:

- Edit homepage headings and descriptions.
- Change homepage images.
- Edit my artist biography.
- Update contact information.
- Upload and replace photographs.
- Add new artworks.
- Edit existing artworks.
- Create public art project pages.
- Add project galleries.
- Reorder images.
- Choose featured artwork.
- Reorder portfolio items.
- Publish and unpublish content.
- Preview changes before publishing.

Provide an easy-to-use rich-text editor where appropriate.

Image uploads should accept files directly from my computer, not require image URLs.

Support multiple images per artwork or project.

Use Supabase Storage with suitable access controls.

Ensure image uploads have sensible file size limits, validation and error handling.

The admin should be straightforward for a non-technical user to operate.

- Single-choice questions.

- Rating scales.
- Short text.
- Long text.

2. Are you a Worcester resident or visiting the area?

- Answers.

- Consent status where applicable.

#### Engagement dashboard

Provide an admin dashboard showing:

- Total responses.
- Responses by project.

- Charts for multiple-choice questions.
- Rating distributions.
- Written feedback.

Security is important because the website will store visitor feedback, contact enquiries and eventually customer orders.

Implement:

- Secure administrator authentication.
- Server-side authorisation.
- Row-level security.
- Input validation.
- Safe file upload handling.
- Protection against spam and abuse.
- Appropriate rate limiting for public forms.
- Secure handling of environment variables.
- No exposed Supabase service-role credentials.
- No unauthorised access to private questionnaire responses.
- No unauthorised modification of website content.
- Secure handling of future ecommerce functionality.

Do not rely on frontend route hiding as a security mechanism.
